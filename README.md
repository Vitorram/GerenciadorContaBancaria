# Bank Account Manager

Aplicação em **Java** para gerenciamento de contas bancárias e prática de fundamentos de Programação Orientada a Objetos.

## Objetivo

Consolidar conceitos de Java em um domínio simples de entender, preparando a base para projetos maiores com Spring Boot.

## Tecnologias e conceitos

- Java
- Programação Orientada a Objetos
- Collections
- Streams
- Exceptions
- JDBC
- MySQL

## Funcionalidades

- Gerenciamento de contas
- Operações bancárias
- Atualização de saldo
- Persistência de dados
- Processamento com Streams

## Destaques técnicos

O projeto busca separar responsabilidades do domínio e demonstrar o uso de recursos da linguagem Java em uma aplicação prática.

## Como executar

1. Clone o repositório:
```bash
git clone https://github.com/Vitorram/GerenciadorContaBancaria.git
```

2. Configure o banco MySQL conforme as configurações existentes no projeto.

3. Abra em sua IDE Java e execute a classe principal.
